# Claude-VL · Máquina de marketing

Sistema de marketing automatizado para Sister y BRIDGE, basado en "The One-Person Marketing Team"
y simplificado sobre Claude + skills + conectores.

- `docs/maquina-de-marketing.html` — diagramas redibujados, inventario de herramientas, plan de armado.
- `docs/herramientas.md` — resumen del stack.
- `marketing-os/` — capa de conocimiento (voz, research, contenido, creativo, distribución, audiencia, analytics).
- `orchestrator/` — pipeline, control, interrupciones y las tres Routines semanales.
