# Plantillas de pitch

## Columna invitada
```
Asunto: [Tema concreto] — columna para [sección]
Hola [nombre]: leí tu nota sobre [nota reciente]. Te propongo una columna sobre [tema], con [dato o caso].
Por qué ahora: [gancho de agenda]. Quién soy: [1 línea]. ¿Te interesa que te mande un borrador de 700 palabras?
```

## Podcast
```
Asunto: Idea de episodio: [título del episodio]
Hola [nombre]: escuché [episodio]. Propongo un episodio sobre [tema] con tres ideas concretas: [1], [2], [3].
Para tu audiencia de [perfil] sirve porque [razón]. Te dejo mi kit de prensa: [link].
```

## Escenario / call for speakers
```
Título · Resumen (80 palabras) · Tres aprendizajes · Para quién · Bio corta · Charlas anteriores
```

## Respuesta a pedido de periodista
```
Respuesta directa a la pregunta en 2–3 frases citables · Un dato o ejemplo · Credencial en 1 línea · Disponibilidad
```
